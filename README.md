# 新生手册刷题

中国石油大学（华东）新生手册 / 学生手册在线刷题网站。纯前端静态页面，无需安装、无需联网，双击即用。

## 使用方法

**方式一（推荐分发）**：直接把 `新生手册刷题-单文件版.html` 发给同学（微信/QQ 均可），对方双击打开即可刷题，一个文件就是整个网站。

**方式二**：保留整个文件夹，双击 `index.html` 打开。

> 想局域网共享的话，在文件夹里运行 `python -m http.server 8765`，同学访问 `http://你的IP:8765` 即可。

## 题库

共 **497 题**，来自两份题库文档：

| 来源 | 题型 | 数量 |
|---|---|---|
| 《新生手册考试题库》 | 单选题 | 157 |
| 《新生手册考试题库》 | 多选题（含 2 道不定项） | 96 |
| 《新生手册考试题库》 | 判断题 | 202 |
| 《学生手册选择模拟》(学长整理) | 填空题 | 42 |

每道题都标注了依据的制度文件（如《本科生学籍管理规定》），方便回归手册原文。

## 功能

- **随机练习**：每次题数可选 20 / 50 / 100 道，从筛选后的题库中随机抽取（筛选范围不足时自动做全部可用题）
- **筛选**：可按题型（单选/多选/判断/填空）和章节（学籍管理、纪律处分、奖学金等 20 个分类）自由组合
- **逐题即时批改**：每答一题立即判对错，显示正确答案和依据，批改后锁定不可改
- **错题集**：错题自动收录，支持逐题展开查看；**连对 3 次自动移出**（普通练习和错题重练中答对都计入连对，答错一次连对清零重新累计）；「错题重练」逐题即时批改并显示连对进度
- **进度保存**：答题中途刷新/关闭浏览器不丢进度（含批改状态）；练习统计、错题集保存在浏览器本地（localStorage）
- **多题型作答**：单选/判断点击即批改，多选勾选、填空逐空输入后点「提交本题」批改（答案归一化匹配，支持 3%/0.03、一/1 等写法变体）

## 文件结构

```
新生手册刷题/
├── index.html                    # 入口页面
├── 新生手册刷题-单文件版.html      # 全部资源内联的单文件版（用于分发）
├── css/style.css                 # 样式
├── js/app.js                     # 应用逻辑
├── js/data.js                    # 题库数据（由脚本生成）
└── tools/
    ├── parse_docx.py             # 从 docx 题库解析生成 data.js
    └── build_single.py           # 生成单文件版
```

## 重新生成题库

如需修改题目或答案（题库源头是 docx 文档）：

1. 修改 `tools/parse_docx.py` 顶部的 docx 路径或其中的 `FILLIN`（填空题答案，含可接受变体）
2. 运行 `python tools/parse_docx.py` 重新生成 `js/data.js`
3. 运行 `python tools/build_single.py` 重新生成单文件版

## 说明

- 填空题答案匹配已做归一化（去空格、全角转半角、忽略大小写、去首尾标点），但个别开放式答案（如"提前1年/延长2年"）仍建议以批改后展示的标准答案为准自查
- 数据仅存在当前浏览器中：换浏览器、换设备或清除浏览记录会清空错题集与统计
